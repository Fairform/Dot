# DOT Mobile — Public Images

Place the following files here:

- `og-default.png`     — 1200×630 Open Graph image (dark background, DOT logo, tagline)
- `logo.svg`           — Full DOT Mobile wordmark, black on transparent
- `logo-white.svg`     — Full DOT Mobile wordmark, white on transparent
- `favicon.ico`        — 32×32 favicon

All images served from /public are cached by Vercel's CDN automatically.
